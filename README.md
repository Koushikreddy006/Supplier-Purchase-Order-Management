# Supplier and Purchase Order Management System

## Project Overview
A Java-based application designed to manage supplier information, product details and purchase orders using a relational database.

## Technologies Used
- Java
- JDBC
- MySQL
- SQL
- Object-Oriented Programming

## Key Features
- Supplier management
- Product management
- Purchase order creation
- Order status tracking
- Database CRUD operations
- Supplier-wise purchase reports

## Database Tables
1. Suppliers
2. Products
3. Purchase Orders
4. Order Items

## Project Objectives
- Understand Java database connectivity.
- Practise SQL queries and database relationships.
- Implement CRUD operations using JDBC.
- Understand procurement and supplier management workflows.

Under Development.
